실제 사용한 로컬 테스트 런타임은 JDK 21.0.12.1, Nginx 1.28.0, Tomcat 10.1.61, MariaDB 11.4.9입니다. 테스트 전용 DB·계정·포트를 사용했으며 기존 Pilot `.env`, 계정 DB, 원본 문서를 재사용하지 않았습니다.

종단 시나리오는 DB 준비 상태, 비인증 접근 차단·정적 자원 MIME, 초기 설정 토큰·origin 제한·최초 설정 1회, 가입 승인과 권한 주입 방지, 역할/상태 변경 시 세션 해제, 서식 CRUD·동시 버전 증가·잘못된 수정의 롤백·버전 복원, 비밀번호 변경·다른 세션 해제·로그아웃, DB 기반 로그인 요청 제한을 포함합니다.

Windows의 네이티브 런타임으로 실제 경로를 검증했습니다. Docker 엔진이 실행 중이지 않아 Compose 컨테이너 기동과 이미지 반입까지는 실행하지 않았습니다. Linux용 빌드 스크립트는 제공했으나 이번 검증은 PowerShell 스크립트로 수행했습니다. 폐쇄망 실행에는 별도로 승인된 런타임 이미지 또는 Nginx·JDK·Tomcat·MariaDB 설치본을 준비해야 합니다.

OCR 처리·검수·내보내기 전체 기능의 Java 이전은 후속 범위입니다. 기존 Pilot의 해당 기능 검증은 Java 이전 완료를 뜻하지 않습니다.
