자동 테스트는 Node 테스트 러너와 JUnit 보고 기준 합계 **104개 통과**입니다. Pilot 비교 17사례는 Java 테스트 내부 데이터이며 합계에 중복 가산하지 않았습니다.

전체 흐름 테스트는 실제 Nginx·Tomcat·MariaDB·FTP 수신기에 별도의 mock OCR 게이트웨이를 연결합니다. 업로드·서명 HTTP·FTP, 상태 조회 재시도, 검수 검증·임시 저장·완료와 원본 보존, 7종 파일 재열기, 샘플 PDF/TIFF, 미저장 서식 OCR, 수동/페이지 수/빈 페이지/서식 경계 분리, 정책 병합·자동 분류 후 재인식·서식 재적용·선택 페이지, 재처리·취소·진단, 텍스트/위치/페이지 차이 비교, 수동/자동 전송·재시도·중복 방지, 운영 관리·권한·초기화를 확인했습니다.

PDF 단위 검증은 상속 글꼴·리소스·CropBox·회전이 있는 문서의 분리 후 검색 텍스트와 픽셀 보존을 포함합니다. XLSX는 한글·검수값·표·긴 문자열·이모지 경계를, CSV는 수식 실행 방지를 확인했습니다.

실제 게이트웨이 검증에는 `192.168.0.25:7777`과 직접 만든 문서를 사용했습니다. 사용자 승인 후 VPN 주소 `192.168.5.6`의 입력 전용 HTTP 18081, FTP 2122 및 패시브 50100~50120을 연결했습니다. 입력 전용 포트의 일반 API는 404로 차단됨을 확인했습니다. Windows 방화벽은 변경하지 않았습니다. 실제 서버의 `STOR /job_....json`은 관리 루트 안에서 활성 작업 이름만 허용하도록 보정했습니다.

검증 런타임: JDK 21.0.12.1, Nginx 1.28.0, Tomcat 10.1.61, MariaDB 11.4.9, PDFBox 3.0.8, POI 6.0.0. 테스트 전용 DB·계정·저장소를 사용했으며 기존 Pilot 계정 DB와 원본 문서는 변경하지 않았습니다. 실제 엔진 확인용 문서와 검수 예제는 로컬 제품판에 보관했습니다.

Windows 네이티브 환경에서 검증했습니다. Docker 엔진이 실행 중이지 않아 Compose 기동·이미지 반입은 실행하지 않았고, Linux 스크립트도 이번 환경에서 실행하지 않았습니다. 폐쇄망에는 승인된 런타임 이미지 또는 개별 설치본이 별도로 필요합니다. 고객망 설치·장시간 부하·다중 WAS 큐 조정은 납품 단계의 추가 검증 대상입니다.

데이터 이전 도구는 서식·버전만 처리합니다. Pilot의 기존 계정·작업·문서 파일 일괄 이전은 별도 작업입니다. Java 정규식과 JavaScript 전용 문법의 완전한 호환은 보장하지 않습니다. OCR 오자는 원본 결과를 보존하면서 검수로 수정합니다. 검색 PDF의 보이지 않는 텍스트층은 원래 OCR이며 검수값은 첨부 JSON에 저장합니다.
