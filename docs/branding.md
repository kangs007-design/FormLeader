# 설치별 브랜딩과 모바일 화면

기존 데스크톱 배치와 업무 흐름을 유지하면서, 공개 브랜딩 설정과 모바일 표시를 분리했습니다. 기본 제품명은 `DocSquare`, 제작사는 `Digitalsquare`입니다.

## Look & feel 설정

수정할 파일은 두 개입니다. Node.js 파일럿과 Nginx 제품판이 같은 `src/web` 파일을 사용합니다.

| 파일 | 변경 항목 |
| --- | --- |
| `src/web/js/brand.config.js` | 제품명, 제작사명, 영문 설명, 로고, 파비콘 |
| `src/web/css/brand.css` | 대표 색상, 선택 배경, 로고·로그인 배경, 글꼴, 모서리 |

`productName: "DocSquare"` 설정은 사이드바·로그인·가입·초기 설정·하단·탭 제목에 함께 반영됩니다. 설치별 제품명도 같은 항목에서 변경합니다. OCR 엔진 정보와 API 헤더에 쓰는 `TextSense`는 엔진·통신 식별자이므로 유지합니다.

로고와 파비콘은 `/vendor/brand/logo.svg`처럼 같은 서버의 정적 파일 경로로 지정합니다. 해당 파일을 `src/web/vendor/brand/`에 넣으면 기존 Nginx 정적 파일 경로와 폐쇄망 패키징을 그대로 이용합니다. `logoUrl`이 비어 있거나 이미지를 불러오지 못하면 기본 아이콘을 사용합니다. 로고는 정사각형 아이콘 영역에 들어갑니다. 원격 URL은 적용하지 않습니다.

`brand.config.js`는 브라우저에 공개되는 파일입니다. 비밀값을 넣지 않습니다.

색상 변경 예시:

```css
:root {
  --brand-accent: #315eb8;
  --brand-accent-hover: #24498f;
  --brand-soft: #edf2fc;
  --brand-ink: #20365b;
  --brand-on-ink: #dce8ff;
  --brand-login-bg: #1c3052;
  --brand-sidebar-bg: #f9fbff;
}
```

대표 색상은 기본 버튼·선택 메뉴·탭·포커스에, 보조 색상은 안내 패널과 로그인 화면에 적용됩니다. 문서 미리보기 그림과 파일 종류 아이콘은 기존 표현을 유지합니다. 성공·오류·검토 필요 색상은 `css/common/tokens.css`에 분리되어 브랜드 변경의 영향을 받지 않습니다. 배경·본문·테두리 등 추가 변경도 `brand.css`에서 `--c-bg`, `--c-text`, `--c-line` 같은 공통 토큰으로 덮어쓸 수 있습니다.

원하는 글꼴 파일도 `/vendor/`에 포함하고 `@font-face`와 `--brand-font`를 설정합니다. 외부 CDN은 필요하지 않습니다. 변경 후 주요 버튼과 글자의 대비를 확인합니다.

제품판은 수정한 웹 파일을 배포 웹 디렉터리에 복사하거나 오프라인 번들을 다시 만듭니다. 설치처의 웹 파일을 직접 수정한 경우 업그레이드 전에 두 설정 파일과 이미지 파일을 보관해 새 번들에 반영합니다. 브라우저 캐시가 남으면 새로고침하거나 HTML의 해당 CSS/JS `v=` 값을 갱신합니다.

## 모바일 메뉴 및 목록

- 900px 이하: 햄버거 버튼으로 사이드바를 열고, 닫기·바깥 영역·Esc·메뉴 선택으로 닫습니다. 메뉴가 열린 동안 배경 조작과 스크롤을 잠그고 키보드 포커스를 메뉴 안에 유지합니다.
- 700px 이하: 최근 문서·전체 문서·사용자·운영 이력을 세로 목록으로 표시합니다. 모든 데이터와 작업 버튼을 유지하며 같은 DOM을 사용합니다.
- 문서 원본의 확대 보기와 OCR 결과의 넓은 표는 각 뷰어·표 영역 안에서 스크롤합니다. 페이지 전체의 가로 스크롤과는 구분합니다.
- 데스크톱 사이드바·표·화면 구성은 유지합니다.
- 처리 활동 카드와 그래프의 높이는 최근 문서 행 수에 따라 늘어나지 않습니다.

## 검증 (2026-11-23)

- 기존 단위·연결 테스트 `npm test`: 78개 통과.
- Edge 브라우저의 320·360·390·600·700·701·768·900·901·1280·1440px 화면에서 주요 메뉴 8개의 페이지 너비 확인. 700px 이하 목록에 가로 스크롤 없음.
- 메뉴의 포커스 순환·Esc·바깥 클릭·선택 후 닫기·화면 너비 전환·도움말 확인.
- 서식 편집, PDF 원본·검수, 계정 팝업, 로그인·가입, 긴 파일명과 빈 목록 확인.
- 별도 샘플 환경에서 모바일 업로드 → API → Mock OCR → 검수 화면 확인. 실제 OCR 서버에는 요청하지 않음.
- 제품명·로고·대표 색상을 다른 설정으로 교체하고, 로그인·메뉴·탭 제목 반영 및 상태 색상 유지 확인. 로고 오류 시 기본 아이콘 대체, 일반 사용자에게 관리자 메뉴 비노출 확인.
- DocSquare 기본 제품명을 로그인·가입·사이드바·하단·브라우저 제목에서 확인. 최근 문서 0·1·6건에서 데스크톱 처리 활동 카드 높이 약 250px, 그래프 높이 93px 유지 확인. 390px 모바일에서도 페이지 가로 넘침 없음.

브라우저 화면 크기를 바꿔 검증했으며 실제 iOS·Android 기기 검증은 포함하지 않습니다.
